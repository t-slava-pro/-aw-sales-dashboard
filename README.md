# BI-дашборд продаж — Analytic Workspace

Интерактивный двухстраничный BI-дашборд для анализа продаж, эффективности менеджеров и KPI. Сделан в Analytic Workspace BI в рамках курса по Business Intelligence — полный цикл от модели данных до интерактивных визуализаций.

## Данные

Данные по эффективности сотрудников — `data/Эффективность сотрудников.xlsx`.

## Стек

Analytic Workspace BI, Spark SQL (CASE WHEN, CAST), вычисляемые поля и агрегаты, интерактивные фильтры.

## Вопросы анализа

1. **Какова динамика выручки и чистой прибыли по месяцам?** Пик выручки — март, после наблюдается снижение.
2. **Какие регионы приносят наибольшую выручку?** Есть выраженные лидеры среди регионов — детально на странице 1 дашборда.
3. **Кто из менеджеров наиболее эффективен по прибыли и рентабельности?** Иванов Пётр лидирует по выручке (275 тыс. ₽), Крестьянин Арчибальд — по рентабельности (59%).
4. **Какие товарные категории дают наибольшую долю прибыли?** Binders and Binder Accessories доминируют в структуре прибыли (26%).
5. **Какие заказы убыточны и почему?** Найдено 10 убыточных заказов, максимальный убыток — 4 443 ₽ (Canon PC1080).

Средняя рентабельность по компании — 22,73%.

## Структура дашборда

**Страница 1 — KPI и динамика продаж:** 5 KPI-карточек (выручка, чистая прибыль, рентабельность, заказы, средний чек), динамика по месяцам, разбивка по регионам, топ менеджеров, методы доставки.

**Страница 2 — Детальный анализ:** эффективность менеджеров, доли прибыли по категориям, топ-10 продуктов по чистой прибыли, топ убыточных заказов.
